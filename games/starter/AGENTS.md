# Game workflow

Keep this file when copying the starter into a new project. Use the Kin checkout's
`AGENTS.md` and `docs/project_workflow.md` for shared scope, reuse, structure and
validation conventions. Inside Kin, use the repository root. In a copied project,
locate the checkout through `KIN_DIR` in the task setup or the existing build's
`CMakeCache.txt`.

Use this game's README for standalone build commands; Kin's presets belong to
the engine repository. Reuse one compatible build, keep game-specific behavior
here, and add files/directories only as real responsibilities require them.
